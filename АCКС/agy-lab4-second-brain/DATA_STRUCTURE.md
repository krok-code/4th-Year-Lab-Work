# Специфікація структури даних персонального Second Brain

## 1. Ієрархія каталогів (Методологія PARA)

Структура базується на стандарті PARA з окремим ізольованим простором для нотаток:

```
agy-lab4-second-brain/
├── notes/
│   ├── Inbox/       # Швидка фіксація необроблених думок і конспектів
│   ├── Projects/    # Активні завдання з конкретними дедлайнами та цілями
│   ├── Areas/       # Довгострокові сфери відповідальності (предмети, курси)
│   ├── Resources/   # База знань, довідники, корисні матеріали, конспекти книг
│   └── Archives/    # Завершені проєкти, минулі семестри, заархівовані нотатки
├── templates/
│   └── note_template.md # Шаблон для генератора нових нотаток
└── DATA_STRUCTURE.md
```

---

## 2. Специфікація метаданих нотатки (YAML Frontmatter)

Кожен файл `.md` повинен містити YAML-блок на початку файлу між розділювачами `---`.

| Поле | Тип | Обов'язкове | Опис | Приклад значення |
| :--- | :--- | :--- | :--- | :--- |
| `title` | `string` | Так | Назва нотатки (збігається або синхронізується з назвою файлу) | `"Лабораторна робота 4 - Second Brain"` |
| `created` | `string` (datetime) | Так | Дата і час створення у форматі `YYYY-MM-DD HH:MM:SS` | `"2026-11-16 11:30:00"` |
| `updated` | `string` (datetime) | Так | Дата і час останньої модифікації | `"2026-11-16 11:35:00"` |
| `tags` | `array<string>` | Так | Список тегів для тематичної класифікації | `["асск", "архітектура"]` |
| `status` | `string` | Так | Поточний життєвий цикл нотатки (`draft`, `active`, `completed`, `archived`) | `"active"` |
| `type` | `string` | Так | Тип документа (`fleeting`, `project`, `area`, `resource`, `archive`, `lecture`) | `"project"` |
| `source` | `string` | Ні | Посилання на джерело інформації (URL, книга, викладач) | `"методичні вказівки кафедри"` |

---

## 3. Обов'язкова структура секцій тіла документа

Тіло нотатки обов'язково містить 3 стандартизовані H2-секції:

```markdown
## Короткий зміст
Лаконічний опис (1-3 речення), що розкриває зміст документа.

## Основні твердження
- Теза 1 з маркером списку
- Теза 2 з формулою або фактом
- Теза 3

## Пов'язані нотатки
- [[Назва нотатки 1]]
- [[Назва нотатки 2]]
```

---

## 4. Специфікація внутрішніх посилань (Wikilinks)

- Формат: `[[Назва нотатки]]` або `[[Назва нотатки|Текст посилання]]`.
- Прив'язка здійснюється за значенням поля `title` або безпосередньо за іменем файлу без розширення `.md`.
- Пошук цільової нотатки здійснюється рекурсивно по всіх категоріях PARA (`Inbox`, `Projects`, `Areas`, `Resources`, `Archives`).
