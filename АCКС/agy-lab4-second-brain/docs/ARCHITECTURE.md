# Архітектура Second Brain

## 1. Загальний огляд

Система побудована за принципом **Local-First**:
- **Storage:** Директорія `notes/` із підкаталогами за методологією PARA (`Inbox`, `Projects`, `Areas`, `Resources`, `Archives`).
- **Server:** Легкий локальний вебсервер на базі стандартної бібліотеки Python (`http.server` або легкий REST API), що читає та створює реальні файли `.md`.
- **Client:** Статичний Vanilla JS фронтенд, що відображає список нотаток, фільтри за категоріями та тегами, повнотекстовий пошук і навігацію за `[[Wikilinks]]`.

## 2. Граф залежностей компонентів

```
┌────────────────────────────────────────────────────────┐
│             Web UI (HTML5 / CSS3 / JS)                 │
│  - Список нотаток & Фільтри (Категорії, Теги)          │
│  - Повнотекстовий пошук з підсвічуванням збігів       │
│  - Навігація за внутрішніми лінками [[Note Title]]     │
│  - Quick Capture Form (збереження у notes/Inbox)       │
└───────────────────────────┬────────────────────────────┘
                            │ HTTP JSON API / Static
                            ▼
┌────────────────────────────────────────────────────────┐
│              Local Server (src/)                       │
│  - REST API: /api/notes, /api/search, /api/create      │
│  - Парсер YAML frontmatter & Markdown секцій           │
│  - Індексатор зв'язків (Backlinks Matrix)              │
└───────────────────────────┬────────────────────────────┘
                            │ File I/O (UTF-8)
                            ▼
┌────────────────────────────────────────────────────────┐
│              File System (notes/ & templates/)         │
│  - notes/Inbox/                                        │
│  - notes/Projects/                                     │
│  - notes/Areas/                                        │
│  - notes/Resources/                                    │
│  - notes/Archives/                                     │
└────────────────────────────────────────────────────────┘
```
