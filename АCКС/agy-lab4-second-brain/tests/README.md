# Модульні та інтеграційні тести

Каталог призначений для тестів:
- Валідація структури YAML frontmatter у нотатках.
- Перевірка наявності обов'язкових секцій: "## Короткий зміст", "## Основні твердження", "## Пов'язані нотатки".
- Тестування парсингу та розв'язання внутрішніх посилань `[[...]]`.
- Перевірка REST API ендпоінтів сервера.
