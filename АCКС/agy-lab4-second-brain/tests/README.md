### Сюїти перевірок, що виконуються автоматично:
1. **Парсинг YAML Frontmatter:** валідація коректності читання `title`, `created`, `updated`, `tags`, `status`, `type`, `source` та відсікання заголовка від тіла.
2. **Повнотекстовий пошук:** перевірка збігів у назві, середині тексту, за тегами та перевірка case-insensitivity.
3. **Фільтрація за категоріями PARA:** ізоляція `Inbox`, `Projects`, `Areas`, `Resources`, `Archives` та вибірка `ALL`.
4. **Фільтрація за тегами:** робота хмари тегів та скидання активного фільтра.
5. **Внутрішні посилання [[...]] та апостроф:** перевірка коректного рендерингу без HTML-сутностей `&#039;` для назв виду `[[MOC - Комп'ютерні системи, Хмари та Штучний Інтелект]]`, резолюція цільової нотатки та розрахунок зворотних лінків (Backlinks).
6. **Обробка порожнього пошуку:** перевірка активації стану Empty State та відображення дружнього повідомлення для користувача.
