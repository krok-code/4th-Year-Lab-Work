# Вихідний код клієнтського Second Brain

Каталог містить автономний вебінтерфейс, який працює **напряму в будь-якому браузері без необхідності встановлення Python, Node.js чи будь-яких вебсерверів**:

- [index.html](index.html) — розмітка робочого простору (Sidebar, список нотаток, перегляд, модальне вікно нової нотатки).
- [styles.css](styles.css) — інженерні стилі, темна тема, стилізація `[[Wikilinks]]`, тегів та карток.
- [app.js](app.js) — автономна логіка:
  - Вбудована база знань із 8 взаємопов'язаних нотаток з категорій PARA (Inbox, Projects, Areas, Resources, Archives).
  - Кнопка **«Завантажити .md файли з папки notes/»** для прямого зчитування Markdown-файлів з диска.
  - Повнотекстовий пошук, фільтрація за категоріями та тегами.
  - Навігація за внутрішніми посиланнями `[[Назва нотатки]]` та автоматичний підрахунок зворотних посилань (Backlinks).
  - Створення нотаток зі збереженням у `localStorage` та завантаженням `.md` файлів на диск.
- `server.py` — опційний сервер стандартної бібліотеки Python (якщо в майбутньому знадобиться мережевий доступ).

## Інструкція запуску

Просто відкрийте файл `src/index.html` у вашому браузері подвійним кліком миші або через `file:///.../src/index.html`.
